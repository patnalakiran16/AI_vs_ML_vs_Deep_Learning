AI, Machine Learning, and Deep Learning Comparison

About the Project

This project explains the basic differences between Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL). It includes simple definitions, real-world examples, and the relationship between these three technologies.

Objective

The main objective of this project is to understand AI, ML, and Deep Learning and how they are related to each other.

Technologies Used

- Python
- Jupyter Notebook
- Markdown

Project Description

In this project, I used Python dictionaries to store information about AI, Machine Learning, and Deep Learning. I used a "for" loop to display their definitions and real-world examples.

The program also explains how these technologies are connected.

Comparison

Technology| Definition| Examples
Artificial Intelligence (AI)| Helps machines perform tasks that require human intelligence| Virtual assistants, expert systems
Machine Learning (ML)| Helps computers learn from data| Spam detection, product recommendations
Deep Learning (DL)| Uses deep neural networks to learn complex patterns| Image recognition, speech recognition

Relationship Between AI, ML, and DL

- AI is the broader field of intelligent machines.
- ML is a subset of AI that learns from data.
- DL is a subset of ML that uses deep neural networks.

Relationship: AI → ML → Deep Learning

How to Run the Program

1. Open Jupyter Notebook.
2. Create a new Python notebook.
3. Copy the Python program into a code cell.
4. Run the cell using "Shift + Enter".
5. Check the output.
